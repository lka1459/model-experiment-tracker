# Model Experiment Tracker

A TypeScript web application for recording, organising, and comparing machine learning model experiments.

The goal of this project is to practise TypeScript fundamentals while building a useful tool for tracking model performance across different datasets and machine learning projects.

## Features

* Record machine learning experiments
* Store model evaluation metrics
* Compare model performance
* Add notes and observations for each experiment
* Simple and responsive web interface

## Technologies Used

* TypeScript
* HTML
* CSS
* Node.js

## Current Status

This project is currently under development.

Planned features include:

* Creating and storing experiment records
* Local storage support
* Sorting and filtering experiments
* Performance comparison dashboard
* Data visualisation and charts

## Purpose

This project was created to:

* Learn TypeScript
* Improve front-end development skills
* Practise working with forms and user input
* Build a useful tool for tracking machine learning experiments
